# Vanilla WinUI 3 Baseline Apps

These are vanilla WinUI 3 (XAML + code-behind) equivalents of the
[Reactor sample apps](../), built by the same AI agent (Claude Opus 4.6)
with the same feature specs — but without Reactor.

They exist as a measurement baseline for comparing AI agent productivity
across frameworks. See [COMPARISON.md](../COMPARISON.md) for results.
